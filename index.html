Generar clasificación oficial PDF

Se abrirá una hoja oficial en una ventana nueva. Desde ahí pulsa Guardar como PDF. El diseño replica la estructura de tu documento de ejemplo: orden, dorsal, equipo, piloto, copiloto, vehículo, categoría, tiempo y penalización.

Plantilla PDF

Con HTML puro no se rellena directamente un PDF existente como si fuera un formulario, salvo que usemos una librería tipo pdf-lib o un backend. Esta opción genera una hoja imprimible con el mismo contenido y estilo de clasificación oficial.
